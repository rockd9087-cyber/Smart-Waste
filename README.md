# Smart Waste - Track. Dispose. Reward.

A citizen engagement platform for real-time waste truck tracking, smart disposal, and eco-rewards.

## Features

- **Live GPS Tracking** 📍 — Real-time truck location with ETA calculations
- **Smart Waste Disposal** 🚪 — Category-based waste segregation with instant credits
- **Rewards System** 🎁 — Eco-credits redeemable at partner merchants
- **Schedule Management** ⏱️ — Ward-level collection timetables

## Tech Stack

- **Frontend**: Vanilla JavaScript, HTML5, CSS3
- **Graphics**: Canvas API for GPS visualization
- **Audio**: Web Audio API for proximity alerts
- **Media**: Webcam API for QR scanning

## Project Structure

```
├── index.html    # Main SPA application
├── style.css     # Styling (41% of codebase)
├── script.js     # Application logic (39% of codebase)
└── .github/      # GitHub configs
```

## Quick Start

   ```bash

   ```


## Usage

- **Track**: View live truck positions on the GPS map
- **Dispose**: Select waste category and deposit via QR scanning
- **Redeem**: Use eco-credits at partner merchants
- **Schedule**: Check collection stops and timings
